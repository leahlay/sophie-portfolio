# sophie-portfolio

Portfolio site for Sophie Livingstone. Static HTML, deployed on Vercel.

- `Portfolio.dc.html` — home
- `About.dc.html` — about
- `Bellavi` / `Fanatix` / `Fertitude` / `JumpWeg` / `Sweatville` — case studies
- `vercel.json` — clean URL routing

Pushes to `main` deploy automatically.
